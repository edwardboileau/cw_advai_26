# Report

This is a starter LaTeX report following the headings in the coursework brief.
The formatting uses a standard article layout; the comments are writing prompts,
not report content or experimental findings.

## Start in Overleaf

1. Create a blank Overleaf project.
2. Upload `main.tex` and `references.bib`, replacing the default `main.tex`.
3. Create a `figures` folder and upload selected figures as you produce them.
4. Open `main.tex` and click Recompile. The default pdfLaTeX compiler works.
5. Replace the student ID and GitHub URL, then write into the sections.

Alternatively, upload `../report-overleaf.zip` as a new project. This ZIP is an
initial snapshot only; it does not update when these source files change.

Add real BibTeX entries to `references.bib`, use `\cite{citation-key}` in the
text, and uncomment the bibliography commands at the bottom of `main.tex`.
The bibliography appears once it is enabled and references are cited.

## Keep GitHub up to date

Use Overleaf as the working copy. Periodically download its source ZIP and
extract the updated `.tex`, `.bib` and figure files into this directory, then
review and commit them. Keep this README when updating the source files.

For submission, download the compiled PDF and rename it `youruserid.pdf`.
Include it with your code in the submission ZIP described in the brief.
